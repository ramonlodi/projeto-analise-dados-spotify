# Dados

O arquivo **não está versionado** neste repositório (direitos e tamanho pertencem ao autor original).

1. Baixe o dataset em <https://www.kaggle.com/datasets/solomonameh/spotify-music-dataset>
2. Extraia **somente** o arquivo `high_popularity_spotify_data.csv`
3. Coloque-o nesta pasta:

```
data/
└── high_popularity_spotify_data.csv
```

Formato esperado: **1.686 linhas × 29 colunas**.

> Ao rodar no **Kaggle**, nada disso é necessário: adicione o dataset ao notebook e o caminho `/kaggle/input/...` é detectado automaticamente.
